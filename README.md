# Famly - Modern Parental Control & Family Activity Monitor

**Famly** adalah aplikasi **Parental Control** modern dan ramah keluarga yang dirancang khusus untuk membantu orang tua memantau aktivitas digital, notifikasi masuk, dan lokasi fisik anak demi keselamatan dan perlindungan keluarga.

---

## 🌟 Fitur Utama

- **🛡️ Perekam & Monitoring Notifikasi Aktivitas Anak**:
  - Merekam secara lokal dan aman seluruh riwayat notifikasi (pesan, pengingat, aplikasi sosial, dll.) pada perangkat anak.
  - Pengelompokan kategori otomatis berbasis AI pintar (Pesan Sosial, Keuangan, Keamanan, Umum).

- **📍 Pelacakan Lokasi Terkini via Bot Telegram**:
  - Memungkinkan orang tua meminta koordinat GPS lokasi fisik anak secara real-time langsung melalui Bot Telegram pribadi.
  - Dilengkapi PIN lokasi native Telegram dan tautan langsung ke Google Maps.

- **🤖 Integrasi Bot Telegram Otomatis**:
  - Meneruskan notifikasi penting dan update lokasi perangkat anak secara langsung ke akun atau channel Telegram orang tua.
  - Opsi perlindungan privasi untuk mengabaikan kode OTP atau kata sandi sensitif secara otomatis.

- **🔢 Penyamaran Ikon (Stealth Calculator Disguise)**:
  - Mode penyamaran yang mengubah icon launcher dan layar utama menjadi Kalkulator Fungsional.
  - Orang tua dapat membuka dasbor Famly rahasia dengan mengetik PIN 4-digit lalu menekan tombol `=` pada kalkulator.

- **🔐 Keamanan & Enkripsi Data Lokal**:
  - Dilengkapi perlindungan PIN 4-digit dan enkripsi data internal.
  - Semua data tersimpan secara lokal di perangkat demi menjaga privasi penuh keluarga.

## 🛠️ Persyaratan Sistem

- **OS Minimum**: Android 8.0 (API Level 26) atau lebih baru
- **Akses Izin**:
  - `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` (Akses Lokasi GPS)
  - `BIND_NOTIFICATION_LISTENER_SERVICE` (Akses Membaca Notifikasi)
  - `INTERNET` (Untuk penerusan data ke Telegram Bot)
